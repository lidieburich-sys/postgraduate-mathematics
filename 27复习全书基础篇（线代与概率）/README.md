# 2027 复习全书基础篇：线性代数与概率论

按章节整理李永乐《线代学习册》《线代严选题》和王式安《概率论学习册》《概率论严选题》，共 49 份 PDF：14 份学习册章节、14 份严选题章节、13 份自测答案，以及 8 份封面目录与附页。

四份原文件共 567 页，全部保留。为保证每章答案完整，7 个跨章共页分别在相邻答案文件中保留一份副本，输出合计 574 页。原扫描页面不裁切。

下表链接旁的页码均为原书印刷页码；每份文件对应的原 PDF 页码见[章节与页码映射](metadata/chapter-map.json)。

严选题中的“例题优选”解析位于对应学习册的“例题解析”部分；“自测答案”仅对应严选题的自测练习题。概率论第五章没有自测练习题及其答案，该章严选题保留例题优选。
